# Práctica 5: Manejo del módulo de captura, comparación y PWM (CCP).

*Enunciado del Laboratorio de Sistemas Digitales II, Julio 2021. Texto adaptado: se omiten el encabezado institucional y las figuras del original.*

## Objetivos
1. Gestionar la configuración del módulo CCP del PIC 18F4550.

2. Implementar el uso del módulo CCP con un microcontrolador PIC 18F4550.

3. Resolver problemas específicos con manejo del módulo CCP del PIC 18F4550.

## Pre-Laboratorio
1. Explicar los tres modos de trabajo del módulo CCP en el PIC 18F4550.

2. Explicar el procedimiento de configuración para cada modo de trabajo del módulo CCP del PIC
18F4550.

3. Indique las funciones en C asociadas al módulo CCP del PIC 18F4550.

## Laboratorio
Experiencia 01: Modo Captura
Medir el ancho de un pulso que se detecta por el módulo CCP del PIC18F4550.

1. Debe ser visualizado en un lcd gráfico el ancho del pulso con su unidad de tiempo.

Experiencia 02: Modo Comparación
Utilizando la aplicación de monitoreo de la práctica 03, realice la captura de:

1. La presión cada 2.5 ms, utilizando el modo especial de comparación y disparo del módulo CCP.

2. Debe ser visualizado en un lcd gráfico el valor de la variable física en kPa y PSI.

Experiencia 03: Modo PWM
Se desea realizar un control de velocidad de un motor DC, para ello utilice el módulo PWM del
PIC. Utilizando el Virtual Terminal, se debe observar un menú de opciones que permita establecer el %
de velocidad del motor, utilice 5 opciones mínimo.
Para la realización de las experiencias cuenta con los siguientes materiales:

Microcontrolador PIC 18F4550.

Motor DC.

Generador de pulso.

MPXA6115A.
