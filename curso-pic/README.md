# Curso de microcontroladores PIC
*PIC microcontroller course*

Ejemplos y ejercicios del curso de programación de microcontroladores PIC en C (CCS) con simulación en Proteus.

| Carpeta | Contenido |
|---|---|
| `2021/sesion-01` a `sesion-08` | Sesiones del curso: puertos, contadores, displays, interrupciones, temporizadores, comunicación serie y maestro/esclavo. Incluye `ejercicios-sueltos`. |
| `2022/tema-02` a `tema-04` | Ejemplos 1–22: entradas y salidas, teclado y LCD, interrupciones, temporizadores, A/D y comunicación entre PIC (maestro/esclavo). Cada ejemplo trae el `.c` y su `.pdsprj`. |

Para probarlo: compilar el `.c` con CCS y cargar el `.hex` en el microcontrolador del `.pdsprj` de Proteus.
