# Legado en lenguaje ensamblador (2008–2011)
*Legacy assembly-language material (2008–2011)*

Programas en ensamblador usados en mis primeras clases de Sistemas Digitales II, antes de migrar a C.

| Carpeta | Contenido |
|---|---|
| `curso-pic-nivel-1` | Ejercicios de un curso de nivel inicial de PIC (EJ1–EJ11). |
| `pic16f870` | Prácticas con PIC16F870: sumas con ajuste decimal, displays, puertos. |
| `laboratorio-2009`, `laboratorio-2011` | Prácticas de laboratorio (matriz de LED, primeras prácticas). |
| `simulaciones-8085` | Ejemplos del microprocesador 8085 (contador, suma decimal). |
| `mplab-suma-daa` | Suma con ajuste decimal en MPLAB. |

Es material histórico: sirve como referencia de la progresión del curso.
