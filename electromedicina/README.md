# Electromedicina: prácticas con PIC18F4550
*Electromedical engineering course: PIC18F4550 practices*

Prácticas que diseñé para el laboratorio de una asignatura de programación de microcontroladores para estudiantes de Ingeniería Electromédica (período 2021-3). Se publican el código en C (CCS) y las simulaciones de Proteus (`.pdsprj`).

| Práctica | Contenido (según el código) |
|---|---|
| 2 | Manejo de puertos de E/S: secuencias de salida, luces secuenciales, contadores ascendente y descendente con display de siete segmentos (`practica02`, `practica022`, `contasc`, `contdesc`, `lucessecuenciales`) y menú en LCD con teclado matricial (`practica023`, `LCDMEN1`). |
| 3 | Temporizador (Timer0), contadores en display y mensajes en LCD (`practica31` a `practica34`, `semaforo`). |
| 4 | Conversión analógica-digital con comunicación serie por interrupción de recepción (`practica4`). |

## Cómo usar
Abrir el `.c` en CCS para generar el `.hex` y cargarlo en el microcontrolador del `.pdsprj` de Proteus. Los archivos compilados no se publican.
